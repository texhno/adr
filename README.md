# Тренажер ADR (ДОПНВ)

Тренажер для курсу перепідготовки ДОПНВ: 273 офіційні питання з Тестів МВС (розділ V), відповіді й пояснення за текстом ДОПНВ.

Сайт: https://texhno.github.io/adr/

## Як змінити

Сайт (`index.html`, `sw.js`) збирається з файлів у `src/`:

- `src/answers.tsv` — відповідь і пояснення до кожного питання: `номер ⇥ літера (a/b/c) ⇥ ⚠ або порожньо ⇥ пояснення`;
- `src/questions.json` — тексти питань і варіантів;
- `src/topics.py` — розподіл питань за темами;
- `src/trener.css` — оформлення;
- `img/` — малюнки до питань.

Після правок перезберіть сайт і запуште:

```
..\.venv\Scripts\python.exe src\build.py
git add -A
git commit -m "Опис змін"
git push
```

GitHub Pages оновлює сайт приблизно за хвилину. Відповіді визначено за текстом ДОПНВ, бо МВС ключа не публікує; питання з позначкою ⚠ варто уточнити в навчальному центрі.
